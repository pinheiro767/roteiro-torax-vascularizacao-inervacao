# Tórax Imersivo — G1 + G2

PWA completo com todas as terminologias do G1 e G2 do roteiro, já com as correções de nomenclatura discutidas.

## Publicar no GitHub Pages
1. Crie um repositório novo.
2. Envie todo o conteúdo desta pasta para a raiz do repositório.
3. Em Settings > Pages, escolha Deploy from a branch, branch main, pasta /root.
4. Aguarde a URL do GitHub Pages.

## Recursos
- Todas as terminologias G1/G2.
- Imagens anatômicas incluídas.
- Busca.
- Modo prática.
- Ampliação de imagens.
- Imagem própria do aluno por estrutura (salva localmente em IndexedDB).
- Gerar PDF: abre a impressão do navegador; selecione “Salvar como PDF”.
- Funciona offline após o primeiro carregamento.

## Recursos imersivos e acessíveis
- Layout responsivo para desktop, tablet e celular.
- Cards com efeito de profundidade/3D em dispositivos com mouse.
- Zoom de imagens em modal, botões +/−, roda do mouse e gesto de pinça em telas touch.
- Alto contraste.
- Aumento e redução de fonte.
- Modo de leitura confortável.
- Opção de reduzir movimento.
- Navegação por teclado e foco visível.
- Leitura em voz alta do card selecionado (TTS do navegador).
- Texto alternativo nas imagens e atributos ARIA.
- Progresso de estudo com “Marcar como memorizado”.

## Interface moderna
- Botão global Ocultar/Mostrar imagens.
- Botão individual em cada card para ocultar/mostrar somente aquela imagem.
- Estado salvo no navegador.
- Visual mais moderno com cartões em glassmorphism leve, gradientes, sombras e melhor responsividade.
